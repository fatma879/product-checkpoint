# Product Card - React Checkpoint

## 📌 Project Description

This project is a React application created as part of a React checkpoint.

The application displays a product card containing a product image, name, price, and description. The product information is stored in a separate product object and is displayed through reusable React components.

The application also displays a personalized welcome message depending on whether a first name has been provided.

## ✨ Features

- Product card built with React-Bootstrap
- Product image
- Product name
- Product price
- Product description
- Reusable React components
- Conditional rendering
- Personalized welcome message
- Conditional welcome image
- Custom styling

## 🛠️ Technologies Used

- React
- JavaScript
- JSX
- React-Bootstrap
- Bootstrap
- CSS
- Create React App
